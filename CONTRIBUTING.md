# Contributing

## Commit messages

Commits are a single line: a gitmoji followed by a short description of
what changed and why. For example:

```
🐛 Fix the default tick rate, which was 100x too low
```

- Use the gitmoji **character itself** (🐛), not the `:shortcode:` text form
  (`:bug:`). Pick whichever emoji from the [gitmoji spec](https://gitmoji.dev/specification)
  best matches the change's intent.
- No body, no blank line, no bullet list.
- No `Co-authored-by:`, `Signed-off-by:`, or other trailers.

This repo's history mixed both emoji forms for a while — new commits use
the literal character form consistently from here on.
